# رامین عمرانی — پورتفولیو

وب‌سایت شخصی و پورتفولیوی دوزبانه (فارسی / English) با تجربه‌ای سینمایی:
ذرات سه‌بعدی WebGL که با اسکرول شکل عوض می‌کنند، انیمیشن‌های GSAP، اسکرول نرم، نشانگر سفارشی، صدای محیطی و ترنزیشن‌های مدرن مرورگر.

## ویژگی‌ها

| بخش | توضیح |
| --- | --- |
| 🎬 پری‌لودر | شمارندهٔ ۰ تا ۱۰۰ و پرده‌ای که کنار می‌رود |
| ✨ صحنهٔ WebGL | ۴۰ هزار ذره با شیدر اختصاصی که در هر بخش به شکل تازه‌ای درمی‌آیند: کره ← حلقه ← `</>` ← اقیانوس ← DNA ← گردباد ← حلقه‌های درهم ← کهکشان. ذرات از نشانگر ماوس فرار می‌کنند، عمق میدان (بوکه) دارند و با سرعت اسکرول آشفته‌تر می‌شوند |
| 🌐 دوزبانه | فارسی راست‌چین و انگلیسی چپ‌چین. تعویض زبان با انیمیشن دایره‌ای (View Transitions API) |
| 🖱️ تعامل | نشانگر سفارشی، دکمه‌های مغناطیسی، کارت‌های سه‌بعدی (Tilt)، متن رمزگشایی‌شونده |
| 📜 اسکرول | Lenis و GSAP ScrollTrigger: گالری افقی نمونه‌کارها، کارت‌های روی‌هم‌چیده‌شده، متنی که با اسکرول روشن می‌شود |
| 🗂️ مطالعهٔ موردی | هر پروژه یک صفحهٔ جزئیات با لینک مستقیم دارد (`#case/nava`) و از کارتش بیرون می‌آید |
| 🔊 صدا | صدای محیطی که با Web Audio ساخته می‌شود، بدون هیچ فایل صوتی. به‌طور پیش‌فرض خاموش است |
| ♿ دسترس‌پذیری | ناوبری با کیبورد، پیوند «رفتن به محتوا»، پشتیبانی از `prefers-reduced-motion` و نسخهٔ جایگزین برای دستگاه‌های بدون WebGL |
| 🔍 سئو | HTML در زمان build از پیش ساخته می‌شود، به‌علاوهٔ داده‌های ساختاریافتهٔ Person، Open Graph و hreflang |
| 🇮🇷 مناسب ایران | همهٔ فونت‌ها و کتابخانه‌ها روی خود سایت میزبانی می‌شوند و به Google Fonts یا CDN خارجی وابسته نیستند |

## ویرایش محتوا

**تمام متن‌ها در یک فایل‌اند:** [`src/content.ts`](src/content.ts)

- هر متن یک نسخهٔ `fa` و یک نسخهٔ `en` دارد.
- کلمه‌ای که بین `*ستاره*` بیاید با رنگ و استایل ویژه نمایش داده می‌شود.
- نمونه‌کارها، آمار و سوابق از رزومه و پروژه‌های گیت‌هاب شما پر شده‌اند. تصویر هر پروژه در `public/projects/` است.
- موارد `sample: true` (فعلاً فقط نظرات مشتریان) **نمونه و موقتی‌اند**. آن‌ها را با اطلاعات واقعی جایگزین کنید و بعد این فلگ را پاک کنید.
  - در حالت توسعه روی این موارد برچسب «نمونه» دیده می‌شود.
  - دستور `npm run build` فهرست همهٔ نمونه‌های باقی‌مانده را چاپ می‌کند.
  - نظرات نمونهٔ مشتریان هیچ‌وقت در نسخهٔ نهایی منتشر نمی‌شوند.
- **تصویر واقعی پروژه‌ها:** فایل را در `public/projects/` بگذارید و در پروژه بنویسید `image: 'projects/nava.webp'`. تا وقتی تصویری نگذاشته‌اید، یک ماکاپ خودکار با رنگ‌های `colors` ساخته می‌شود.
- ایمیل، شبکه‌های اجتماعی و آدرس نهایی سایت (`url`) را در بخش `site` تنظیم کنید.
- زبان پیش‌فرض با `site.defaultLang` تعیین می‌شود.

## اجرا

```bash
npm install
npm run dev      # سرور توسعه روی http://localhost:5173
npm run build    # ساخت نسخهٔ نهایی در پوشهٔ dist
npm run preview  # پیش‌نمایش نسخهٔ نهایی
```

## انتشار

**GitHub Pages:** در تنظیمات مخزن به **Settings → Pages** بروید و گزینهٔ **Source** را روی **GitHub Actions** بگذارید. از آن به بعد با هر push به شاخهٔ `main`، سایت به‌طور خودکار منتشر می‌شود.

**هاست ایرانی یا هر هاست دیگر:** خروجی `dist` یک سایت کاملاً استاتیک است. کافی است محتوای آن را روی هر هاستی (لیارا، آروان، Netlify، Vercel و…) آپلود کنید. برای مخاطب داخل ایران، یک هاست ایرانی با دامنهٔ `.ir` سریع‌تر و پایدارتر است.

## اسکیل‌های Claude Code

پوشهٔ [`.claude/skills`](.claude/skills) ده اسکیل طراحی و انیمیشن از [emilkowalski/skills](https://github.com/emilkowalski/skills) (مجوز MIT) دارد. هر جلسهٔ Claude Code روی این مخزن آن‌ها را خودکار بارگذاری می‌کند:

- **خودکار:** `emil-design-eng`، `animate`، `improve-animations`، `find-animation-opportunities`، `animation-vocabulary`، `apple-design` و `mobile-native`. هر وقت کار به انیمیشن یا رابط کاربری مربوط باشد، Claude خودش سراغشان می‌رود.
- **فقط با دستور شما:** `/review-animations` (بازبینی سخت‌گیرانهٔ انیمیشن‌ها)، `/prototype` (ساخت چند نسخهٔ مختلف از یک بخش برای انتخاب) و `/pick-ui-library` (انتخاب کتابخانهٔ مناسب).

## نسخهٔ سوم: پوشهٔ `v3`

روشن مثل نسخهٔ دوم، سینمایی مثل نسخهٔ اول. بعد از انتشار در آدرس `/v3/` در دسترس است.

| بخش | توضیح |
| --- | --- |
| 🎬 فیلم معرفی | یک صحنهٔ سه‌بعدی (Three.js) روی شفق رنگی زنده: لپ‌تاپ، تبلت و گوشی واقعی با اسکرین‌شات پروژه‌ها. درِ لپ‌تاپ هنگام ورود باز می‌شود، با اسکرول دوربین وارد صفحهٔ لپ‌تاپ می‌شود و چهار سامانهٔ واقعی (ذهن سبز، دوپینگ شیمی، CRM، پشتیبانی) را نشان می‌دهد، بعد گوشی می‌چرخد و پنج صفحهٔ اپلیکیشن (از جمله دنگی) را ورق می‌زند. عکس رامین در یک طاق ایرانی کنار دستگاه‌ها می‌نشیند، با امضای نستعلیق و برچسب‌هایی که با ماوس جابه‌جا می‌شوند |
| 🗂️ نمونه‌کارها | کارت‌های سه‌بعدی که با ماوس کج می‌شوند. هر کارت با انیمیشن View Transitions به صفحهٔ کامل «داستان پروژه» تبدیل می‌شود (`#work-crm`) |
| 🤖 ربات زنده | دموی فورواردبات قابل بازی است: هر دکمه همان جوابی را می‌دهد که ربات واقعی می‌دهد |
| 🧰 خدمات | فهرست خدمات با یک ویترین چسبان که همراه اسکرول عوض می‌شود |
| 💬 تماس | تماس (۰۹۰۱ ۷۰۲ ۱۱۶۶)، واتس‌اپ (۰۹۳۶ ۵۷۴ ۳۴۵۸)، تلگرام (@Daneshjoo_AI) و ایمیل؛ به‌علاوهٔ یک گفت‌وگوی سی‌ثانیه‌ای که پیام اول مشتری را آماده می‌کند |
| ♿ دسترس‌پذیری | بدون WebGL یک تصویر ثابت نشان داده می‌شود؛ با «کاهش حرکت» دوربین آرام می‌ماند و حلقه‌های انیمیشن خاموش می‌شوند |

**ویرایش:** اطلاعات تماس در [`v3/src/data/site.ts`](v3/src/data/site.ts)، متن‌ها در [`v3/src/data/copy.ts`](v3/src/data/copy.ts)، پروژه‌ها در [`v3/src/data/projects.ts`](v3/src/data/projects.ts) و جواب‌های دموی ربات در [`v3/src/data/bot.ts`](v3/src/data/bot.ts).

```bash
cd v3
npm install
npm run dev
npm run build    # خروجی در v3/dist
```

**تکنولوژی‌ها:** React 19، Three.js و React Three Fiber، شیدر GLSL اختصاصی، GSAP ScrollTrigger، Lenis، Motion، View Transitions API، فونت وزیرمتن (متن)، استعداد (تیترها) و نوتو نستعلیق (فقط چند کلمهٔ تأکیدی).

**هویت بصری:**

- **رنگ‌ها** از کاشی‌کاری ایرانی آمده‌اند: لاجوردی `#1F52D6`، فیروزه‌ای `#0E9AA7` و زعفرانی/طلایی `#E9A23B` روی زمینهٔ عاجی `#F6F4EF`. همه در `:root` فایل [`v3/src/styles/base.css`](v3/src/styles/base.css) تعریف شده‌اند.
- **فونت‌ها:** سایت‌های بزرگ فارسی (اسنپ با IRANSansX، بازار با یکان‌بخ، دیوار با IRANSans، دیجی‌کالا با فونت اختصاصی) فونت تجاری فونت‌ایران دارند؛ اینجا معادل‌های رایگان و متن‌باز همان سبک استفاده شده. اگر لایسنس IRANSansX یا یکان‌بخ را خریدید، کافی است متغیرهای `--font` و `--font-display` را عوض کنید.
- **نشانه‌گذاری متن:** در فایل‌های داده، `{...}` یعنی گرادیان رنگی و `[...]` یعنی نستعلیق با افکت نوشته‌شدن با جوهر.
- **لوگو:** حرف «ر» سفید داخل یک طاق طلایی، روی کاشی لاجوردی. فایل‌ها در [`v3/public/brand`](v3/public/brand): `logo-mark.svg` (برداری)، `logo-mark-512.png`، `icon-192.png` و `logo-lockup.png` (لوگو با نام، برای پروفایل‌ها و فاکتور). کامپوننت آن [`v3/src/ui/Logo.tsx`](v3/src/ui/Logo.tsx) است.
- **عکس‌ها** در [`v3/public/me`](v3/public/me): هیرو، بخش «درباره»، سؤال‌های متداول، تعهد، تماس و آواتار گفت‌وگو.
- **دامنهٔ پیشنهادی:** `raminomrani.ir` (برای مشتری ایرانی آشنا و قابل‌اعتماد؛ ثبت از nic.ir) و در صورت نیاز `omrani.dev` برای مخاطب خارجی. قبل از خرید، آزاد بودن دامنه را چک کنید و بعد مقدار `domain` را در `site.ts` عوض کنید.

## ساختار پروژه

```
src/
  content.ts      ← همهٔ محتوا (فقط همین را ویرایش کنید)
  render.ts       ← ساخت HTML از محتوا (هم در build و هم در مرورگر اجرا می‌شود)
  main.ts         ← راه‌اندازی: زبان، اسکرول نرم، WebGL، پری‌لودر
  page.ts         ← انیمیشن‌ها و تعامل‌های همهٔ بخش‌ها
  gl/             ← صحنهٔ ذرات Three.js، شیدرها و شکل‌ها
  fx/             ← نشانگر، دکمهٔ مغناطیسی، متن رمزگشا، مارکی و صدا
  styles/         ← استایل‌ها
```

**تکنولوژی‌ها:** Vite، TypeScript، Three.js، GSAP (ScrollTrigger)، Lenis، View Transitions API، CSS Container Queries، `@starting-style` و `::details-content`
